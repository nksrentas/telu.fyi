## Trust Boundaries

| Boundary | Description |
|---|---|
| React → Tauri start | Renderer supplies preferences but cannot supply canonical identity/lifecycle. |
| Rust → SQLite | Rust persists identity before native capture. |

## STRIDE Threat Register (ASVS L1; High blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Spoofing / Tampering | start command and TranscriptContext | high | mitigate | Rust mints IDs, validates lifecycle, and tests reject renderer-created/remapped IDs. |
| T-01-02 | Repudiation | legacy lifecycle migration | medium | mitigate | Preserve completion-unverified reason rather than asserting unsupported history. |
| T-01-03 | Information disclosure | start/event logging | medium | mitigate | Log IDs and typed codes only; exclude content, secrets, and full paths. |
</threat_model>
