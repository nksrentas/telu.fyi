<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Manifest/reference profile → runner | Inputs determine claimed environment/workload/route behavior. |
| Local bundles → threshold/gate | Raw measurements become readiness claims. |
| App ledger → OS observation | Independent sources must reconcile. |

## STRIDE Threat Register (ASVS L1; High blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-19-01 | Tampering / Repudiation | scenario/threshold report | high | mitigate | Versioned manifests, immutable run IDs/hashes, outlier retention, post-declaration validation. |
| T-19-02 | Spoofing | reference environment/method | high | mitigate | Blocking human approval and preflight comparison. |
| T-19-03 | Information disclosure | evidence/report | high | mitigate | Redacted bundles and sanitized relative references/checksums. |
| T-19-04 | Information disclosure / Repudiation | network canary | high | mitigate | Independent OS method plus app ledger; unmatched/missing evidence fails. |
| T-19-05 | Tampering | battery claim | medium | mitigate | Approved method/uncertainty with unknown-as-fail. |
</threat_model>

<verification>
Matrix test proves manifest/order/distinct identity/no silent pass; runner validates bundles and declaration ordering; checkpoint approves hardware/power/network methods; physical UAT reconciles packaged behavior and OS observations.
