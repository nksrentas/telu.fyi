<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Raw local bundle → renderer detail | Only redacted query-safe fields cross IPC. |
| Renderer export → selected directory | User path/content choices drive local sanitized copy. |
| Raw bundle → copy | Redaction reapplies; source never mutates/uploads. |

## STRIDE Threat Register (ASVS L1; High blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-18-01 | Information disclosure | detail IPC | high | mitigate | Typed redacted projections and serialization scans. |
| T-18-02 | Information disclosure | export | high | mitigate | Toggles reset off, separate consent, sanitized local copy, no upload. |
| T-18-03 | Tampering | destination/path | high | mitigate | Selected-directory scope, generated child, validation, atomic copy. |
| T-18-04 | Repudiation | inclusion policy | medium | mitigate | Export manifest records categories/policy/choices/result. |
</threat_model>
