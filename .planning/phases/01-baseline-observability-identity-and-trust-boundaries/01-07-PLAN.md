## Phase Goal

**As a** Telu user or maintainer, **I want to** rely on a measured, recoverable desktop foundation with one meeting identity and explicit local, LAN, or remote data boundaries, **so that** I can trust the foundation before Telu adds product intelligence.

<objective>
Instrument the authoritative identity/evidence/queue lifecycle and serialize repeatable, content-redacted local run evidence.

Purpose: Make transcript freshness, backlog, resource use, provider/error behavior, and UI acknowledgement inspectable without hosted telemetry or invented thresholds.
Output: Monotonic stage clock, resource sampler, evaluation schema/repository, atomic run-bundle writer, and bundle contract tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Hot capture/worker → observability channel | Sensitive latency path emits compact telemetry under capacity constraints. |
| Runtime records → SQLite/run bundle | Measurements and errors become durable local diagnostic evidence. |
| App-data bundle path → later export/UI | Local raw artifacts must remain contained and content-redacted by default. |

## STRIDE Threat Register (ASVS L1; High blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-01 | Information disclosure | telemetry/error/bundle fields | high | mitigate | Allowlist schema, redaction tests, content-free defaults, sanitized origins, no keys/full paths. |
| T-07-02 | Tampering / Repudiation | run/stage ordering | high | mitigate | Version/run IDs, monotonic offsets, stable sequence, append-only uniqueness, and validator. |
| T-07-03 | Denial of service | observability channel/writer | high | mitigate | Bounded non-blocking hot admission, overflow counters, batched off-path persistence. |
| T-07-04 | Tampering | bundle path/atomicity | high | mitigate | Tauri app-data path, generated run IDs, temp-write/rename, and interrupted-write validation. |
| T-07-05 | Information disclosure | diagnostic export precursor | high | mitigate | Raw bundles stay local; registered commands are read/list/finalize only and expose redacted summaries. |
</threat_model>
