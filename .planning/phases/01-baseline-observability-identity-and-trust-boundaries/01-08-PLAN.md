<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Local raw bundle → renderer detail | Only redacted/query-safe diagnostic fields cross IPC. |
| Renderer export request → selected filesystem destination | User-controlled path and content choices drive a local sanitized copy. |
| Raw bundle → exported copy | Copying must reapply redaction and never mutate/upload the source. |

## STRIDE Threat Register (ASVS L1; High blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-01 | Information disclosure | diagnostics detail IPC | high | mitigate | Typed redacted projections; no content/keys/full paths; backend tests scan serialized output. |
| T-08-02 | Information disclosure | diagnostic export | high | mitigate | Sensitive toggles default/reset off, explicit separate consent, re-sanitized local copy, no upload code. |
| T-08-03 | Tampering | export destination/path | high | mitigate | Dialog-selected directory scope, generated child name, path validation, atomic copy, source remains immutable. |
| T-08-04 | Repudiation | export inclusion policy | medium | mitigate | Export manifest records categories/redaction/content choices and local destination result without content. |
</threat_model>

<verification>
- Rust tests scan detail/export serialization for redacted defaults, safe paths, and immutable source behavior.
- Node contract test covers exact empty/privacy/export copy, sensitive toggle resets, and local-only implementation.
- Frontend build verifies Settings tab/detail/dialog integration.
</verification>

<success_criteria>
