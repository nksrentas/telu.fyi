<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Network-capable subsystems → destination | Providers, updater, analytics, and model traffic cross the device boundary. |
| Renderer → filesystem plugin | WebView requests access to local files/app data. |
| App attribution ledger → OS network observation | In-app intent records are reconciled with an independent block/capture mechanism. |

## STRIDE Threat Register (ASVS L1; High blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-01 | Information disclosure / Repudiation | undisclosed egress | high | mitigate | Pre-dispatch bounded attribution, canary-first startup, OS-level reconciliation in Plan 09, and fail on unattributed traffic. |
| T-06-02 | Elevation of privilege / Information disclosure | renderer filesystem capability | high | mitigate | Remove global read/write, scope app data, and require explicit selected-file authority with packaged regression checks. |
| T-06-03 | Tampering | canary configuration | high | mitigate | Run-scoped Rust state, no persistent setting mutation, manifest snapshot, and tests for restoration. |
| T-06-04 | Information disclosure | outbound ledger | high | mitigate | Allowlisted metadata and sanitized origins only; no payload/content/keys/full paths; bounded storage. |
</threat_model>
