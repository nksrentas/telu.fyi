## Phase Goal

**As a** Telu user, **I want to** turn a completed meeting into trustworthy typed knowledge, inspect its exact evidence, and control what becomes eligible for future use, **so that** only reviewed knowledge I can trace to the exact transcript words is carried into later meetings.

(The story is the one every Phase 2 plan already carries; the ROADMAP goal line itself is not in story form, and this gap run does not rewrite it.)

<objective>
Close verification gap 1 (KNOW-05 / SC3, review CR-02): a claim the user rejected must never come back as a new suggestion when Regenerate re-emits it under a different type, and neither may wording the user corrected away. Make the KNOW-07 resurrection measure non-tautological (review WR-06) so the eval harness can detect this class of defect.

Purpose: Rejected-item resurrection is a named Phase 2 stop condition, and Phase 3 will read `list_eligible_items`; a resurrected rejection that the user accepts again would reach preparation context.
Output: A type-agnostic rejected and superseded-wording match in `matcher.rs`, the current/superseded key split in `load_match_index`, regression tests at unit and regenerate level, and a resurrection measure that goes red against the pre-fix matcher.
</objective>
