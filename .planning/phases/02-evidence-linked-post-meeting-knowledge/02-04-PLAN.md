Purpose: D-01 requires one design system app-wide; later plans (re-skins, shell, living doc) build on these tokens and primitives.
Output: Token CSS, Tailwind config, layout font/motion/toast changes, `motion.ts`, `telu-palette.mjs` with tests, Telu Button, and six `telu-ui` primitives.
</objective>
