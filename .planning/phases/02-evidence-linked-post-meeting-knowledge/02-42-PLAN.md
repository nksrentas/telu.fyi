## Phase Goal

**As a** Telu user, **I want to** turn a completed meeting into trustworthy typed knowledge, inspect its exact evidence, and control what becomes eligible for future use, **so that** only reviewed knowledge I can trace to the exact transcript words is carried into later meetings.

<objective>
The explicit development gate before the new held-out evaluation. A held-out set can be spent only once per threshold version, so it is used only when the development set already meets every declared threshold. If the improved local extraction still misses, the user decides how to proceed instead of the run spending the held-out set on a known failure.

Purpose: protect the new held-out set and keep provider, model and gate choices with the user.
Output: `eval/development-report.json` committed alone, and either a recorded pass or the user's recorded choice.

No tracer task: this plan records a measurement and a decision; it writes no code.
</objective>
