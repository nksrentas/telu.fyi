## Phase Goal

**As a** Telu user, **I want to** turn a completed meeting into trustworthy typed knowledge, inspect its exact evidence, and control what becomes eligible for future use, **so that** only reviewed knowledge I can trace to the exact transcript words is carried into later meetings.

<objective>
Stand up the visual-regression harness that D-01 requires and capture the "before" gallery of every existing screen, so the design-system migration and the new shell can be reviewed screen by screen against a fixed baseline.

Purpose: The token migration touches about 70 files; without a before/after gallery there is no evidence that existing screens survived it.
Output: Pinned Playwright WebKit install (after a legitimacy gate), a Tauri IPC stub, declarative screen fixtures, a `gallery` script, and committed before-migration PNGs in light and dark.
</objective>
