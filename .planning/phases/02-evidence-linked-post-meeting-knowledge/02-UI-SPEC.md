## Color

All values are the LOCKED Telu tokens (light theme shown; dark values are in foundations-and-motion.md › Tokens and ship in the same block). Tailwind maps colors straight to variables (no `hsl()` wrapper); opacity modifiers like `bg-accent/50` are not used — use `-soft` / `-softer` tokens or `color-mix()`.

| Role | Token · Value (light / dark) | Usage |
|------|-------|-------|
| Dominant (60%) | `--content-bg` `#FFFFFF` / `#1F2026` | Main column, meeting page, side peek, fields, popup buttons |
| Secondary (30%) | `--sidebar` `rgba(234,234,230,0.6)` over native vibrancy · `--window-bg` `#F7F7F4` / `#1B1C21` · `--surface-sunken` `#F4F4F0` / `#1A1B20` · `--surface` `#FFFFFF` / `#26272E` | Sidebar material, window backdrop, candidate wells, event cards |
| Accent (10%) | `--accent` `#6366E8` / `#7C7FF2` (hover/pressed `--accent-strong` `#4F52D9`; fills `--accent-soft` 13%, `--accent-softer` 6%) | See reserved list below |
| Destructive / recording | `--coral` `#FF6B62` (text `--coral-ink` `#E0463D` / `#FF8A83`; fill `--coral-soft`) | Record glyph and Record button, recording capsule, rec dots, the delete Alert primary button, danger menu rows (`Delete meeting…`) |
| Needs review | `--amber` `#E8930C` / `#FFB340` (fill `--amber-soft`) | Pending-candidate 2.5px bar, "N to review" chips, question type, "Owner not stated"/"Due not stated" when accepted-unresolved, "Evidence changed", "Incomplete · N gaps" chip |
| Text | `--label` `#17191F`, `--label-2` `#727783`, `--label-3` ink 38%, `--label-4` ink 20% | Four label levels |
| Structure | `--separator` ink 8%, `--hairline` ink 12%, `--fill`/`--fill-2`/`--fill-3` ink 4.5/7.5/11% | 0.5px hairlines instead of borders; control fills |
| Glass | `--glass-strong` `rgba(251,251,249,0.84)` + blur/saturate recipe per layer | Toolbar groups, popovers, menus, toasts, drawer, alert |

Accent is reserved for exactly these elements:
1. `primary` buttons (the one main action on a surface: `Find knowledge`, `Save correction` in Correct, `Regenerate` in the regenerate notice, `Try again`).
2. `tinted` buttons: `Accept` on a candidate, toast `Undo`.
3. Sidebar row icons (Today `sun`, Review `inbox`) — icons only, never row fills.
4. Selection: the 2px ring on a selected agenda card; the accent-filled active menu row; cmdk selected result row.
5. Links and the doc-toolbar Back label (`‹ Today`).
6. Focus: `:focus-visible` outline at 45% (`color-mix`), field ring at 32%.
7. Evidence highlight in the transcript (`--accent-soft` line, quote span `--accent-soft` + `--accent-strong` text) and the reveal/receive flash.
8. Decision knowledge type (label and icon).
9. Popover evidence quote bar (2px `--accent-soft`).

Never accent: row hover, card backgrounds, sidebar selection fill (that is `--fill-2`), body text, decorative icons.

Mint (`#67E8C5`) is **not used in Phase 2** (its only meanings, Worth asking and the Island, are out of scope). Knowledge-type colors reuse the palette: commitment `--series-orange` `#FF9F0A`, fact `--series-teal` `#2FA8C0`. Color is never the only signal: every chip, dot and state also carries text or a glyph.

## Knowledge Section Contract (KNOW-01..06, D-06, D-09, D-11..D-16)

Section head: eyebrow `KNOWLEDGE` · caption `· {n} to review` (amber text only when > 0) · spacer · `⋯` menu (`aria-label="Knowledge actions"`): `Regenerate…`, `Run details`.

### Run notice (provider label before the data-bearing call — Phase 1 D-18/D-19)

Shown above any Find/Regenerate action and above a running run; one line, 12px:
`{route icon} Uses your Summary model · {Local|LAN|Remote} · {sanitizedOrigin}` (Assumption A4). Icons: Local `laptop`, LAN `network`, Remote `cloud`. LAN without encryption adds coral-ink `Not encrypted`. If the route is not `validated`, the action is disabled and the line reads the ProviderBoundary unavailable copy (see Copywriting). No silent fallback. Choosing `⋯ › Regenerate…` shows this line inline with `Regenerate` (primary sm) and `Keep current items` (plain sm, dismisses the notice without starting a run).

### Run states

| State | Trigger | Renders |
|-------|---------|---------|
| Not run · auto pending | auto-generate on + `completeness = complete` + route validated + no run yet | Spinner row `Reading the transcript…` immediately (auto-start, D-09) |
| Not run · explicit start | auto off, or completeness `incomplete` / `recovered_with_gaps` | Sunken card (radius 12, 14px padding): heading `No knowledge yet` (13px/600), body (see Copywriting), for gap meetings the completeness alert text, run notice line, `primary` sm button `Find knowledge` (gap meetings: `Find knowledge anyway`) |
| No evidence | `KNOWLEDGE_NO_EVIDENCE` (legacy, imported, retranscribed meetings) | Sunken card, no button: see Copywriting "No evidence" (Assumption A2) |
| Running | run `running` | Spinner (14px) + `Reading the transcript…` + plain sm `Stop` (cancels the run). Existing items stay visible during a regenerate |
| Failed | run `failed` | Sunken card with coral-ink glyph `circle-x`, error copy by code, `primary` sm `Try again` |
| Succeeded · items | ≥ 1 visible item | ReviewHead + abstention line + candidate list + Rejected (n) |
| Succeeded · nothing found | 0 items, 0 skipped | EmptyState (compact, no badge): `Nothing to review` / body |
| Succeeded · all abstained | 0 items, ≥ 1 skipped | EmptyState compact: `Nothing Telu could quote` / body + abstention line |

### ReviewHead (`role="status"`)
Amber `eye` glyph + note 12px `--label-2`; spacer; `Accept all` (plain sm) only when ≥ 2 pending. States: several pending, one pending, reviewed (no button, glyph `circle-check` `--label-3`).

### Abstention line (D-15, KNOW-06)
Directly under ReviewHead when `skipped_count > 0`: `info` glyph 13px + 12px `--label-3` text `{n} possible items skipped — not enough evidence`, with a tooltip `Telu only shows items it can quote word for word from this transcript.` Content-free: no list of skipped text.

### CandidateRow (D-12..D-16)
Grid `112px · 1fr · auto`, gap 12, padding `10px 12px 10px 14px`, radius 12, rows 8px apart; compact (≤ 600px) stacks to one column.

| State | Visual | Actions |
|-------|--------|---------|
| Pending | `--surface-sunken`, 2.5px amber left bar (inset 12px) | `Accept` (tinted sm) · `Correct` (default sm) · Reject (plain sm icon `x`, `aria-label="Reject"`) |
| Correcting | Text becomes a textbox (`--content-bg`, accent inset ring + 3px ring at 22%), text selected; below it two 28px fields `Owner` and `Due` (12px labels, placeholder `Not stated`) | `Save correction` (primary sm) · `Discard edit` (plain sm). Enter in the text saves, Esc discards the edit. Unchanged fields = plain accept |
| Accepted | Transparent with 0.5px `--separator` ring; status `✓ Accepted · eligible` (11px, green `--series-green` dot) | `⋯` (plain sm icon): `Correct…`, `Move back to review` (appends `reopen`) |
| Accepted · corrected | As accepted; status `✓ Corrected · Accepted · eligible` where `Corrected` is a button opening the History popover | Same `⋯` |
| Accepted · unresolved | Accepted with owner or due `not_stated`: dashed chip stays and turns amber text `Owner not stated` / `Due not stated` | Fill it via `Correct…` |
| Evidence changed / missing (KNOW-08) | Status replaces `eligible`: amber dot `Evidence changed — not eligible` / `Evidence missing — not eligible`; SourceChip shows `alert-triangle` | `Reject`, `Correct…` still available |
| Rejected | Moves instantly into the Rejected (n) group; text `--label-3`, line-through `--label-4` | `Restore` (plain sm) |

Row content, top to bottom in the main cell: text (13px, plain React text node — never HTML) · meta row (gap 8): owner (`user` 12px glyph + name) or dashed chip `Owner not stated` · due (`clock` glyph + verbatim text such as `by Friday`) or dashed chip `Due not stated` · SourceChip pushed right. Owner/due chips for `not_stated` are `.chip.dashed` in `--label-3` (weaker, dashed — D-16). Type column: KnowledgeType label (icon + 11px/600) in its color.

State swaps are instant (no row animation). After Accept, focus moves to the next pending row. `Accept all` appends one accept per pending row, 70ms apart, then one toast with Undo.

### Rejected (n) group (D-14)
A Collapsible at the bottom of the review list (inside the block headed by ReviewHead — Assumption A6), collapsed by default: header button `Rejected (2)` with 13px `--label-3` chevron (rotates 90°, 200ms), `aria-expanded`. Hidden when n = 0. Rows show type, struck-through text, SourceChip and `Restore`.

### SourceChip + EvidencePopover (KNOW-02)
