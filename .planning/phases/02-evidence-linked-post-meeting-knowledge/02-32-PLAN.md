## Phase Goal

**As a** Telu user, **I want to** turn a completed meeting into trustworthy typed knowledge, inspect its exact evidence, and control what becomes eligible for future use, **so that** only reviewed knowledge I can trace to the exact transcript words is carried into later meetings.

<objective>
Let the user declare the KNOW-07 quality thresholds in thresholds-v2.json, in a commit of their own, before any representative scoring (verification gap 3, human activity). At 02-20 the user chose "pilot first"; this checkpoint is where they either declare values or keep KNOW-07 open.

Purpose: The Phase 2 exit gate requires thresholds declared before evaluation; numeric targets are never invented by the planner or the executor.
Output: Either an unchanged repository (thresholds kept undeclared) or a declared thresholds-v2.json committed alone, followed by a re-derived status file and a re-bound synthetic report.

No tracer task: this plan contains no code path. It is a human decision, a verbatim transcription and a re-derivation, all verified by the 02-28 module.

Scope note: three sequential, human-gated tasks, kept separate on purpose: the checkpoint:decision must resolve before anything is written, and the thresholds file must be committed alone (Task 2) before the status is re-derived and the synthetic suite re-scored (Task 3).
</objective>
