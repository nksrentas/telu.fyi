# Color palette

## Direction

The brand should feel like a quiet intelligence sitting beside the user during a conversation. The visual language should be calm, precise, warm, and native to a high-quality desktop application—not a generic neon or gradient-heavy “AI” aesthetic.

The core combination is **Ink + Warm off-white + Telu Indigo**, with mint reserved for meaningful moments when Telu has found something useful.

## Palette

| Role | Name | Hex | Intended use |
| --- | --- | --- | --- |
| Primary | Telu Indigo | `#6366E8` | Primary actions, selected states, links, and the brand mark |
| Intelligence / live assist | Fresh Mint | `#67E8C5` | Sparse signals that Telu has found a useful insight or question |
| Main dark | Ink | `#17191F` | Primary text, strong icons, and high-contrast surfaces |
| Secondary text | Slate | `#727783` | Supporting copy, metadata, and lower-emphasis labels |
| Main background | Warm Off-white | `#F7F7F4` | Primary application background |
| Cards | White | `#FFFFFF` | Cards, panels, and elevated content surfaces |
| Borders | Soft Grey | `#E6E6E2` | Dividers, outlines, and subtle structure |
| Recording / attention | Soft Coral | `#FF6B62` | Recording state, destructive warnings, and genuine attention states only |

## Usage principles

### Default interface

- Background: `#F7F7F4`
- Primary typography: `#17191F`
- Primary actions: `#6366E8`
- Supporting typography: `#727783`
- Surfaces: `#FFFFFF`
- Borders: `#E6E6E2`

### Live meeting behavior

Use `#67E8C5` very sparingly. A small mint pulse, dot, or highlight can mean:

> Telu found something worth asking or remembering.

Mint should remain a semantic signal, not a decorative accent spread throughout the interface. If it appears everywhere, it loses its meaning.

Use `#FF6B62` only for recording and states that genuinely require attention. It should not compete with indigo as a general accent.

## Logo direction

- Prefer a single-color abstract mark in Telu Indigo (`#6366E8`).
- Explore a visual idea that moves from **conversation → connection → insight**.
- Pair the mark with the lowercase wordmark **telu**.
- Use a geometric typeface that is rounded enough to feel approachable but not cute.
- Avoid multicolor AI gradients, glowing purple effects, robot imagery, and literal microphone symbols unless later exploration proves them distinctive.

The intended overall character is comparable to modern, restrained native productivity tools while remaining recognizably Telu.
